# Приёмка Qidi Admin Studio на Windows

Этот чек-лист проверяет именно объединённое нативное приложение: вкладки
OrcaSlicer «Подготовка» и «Просмотр» должны работать совместно с Raspberry
Qidi Admin Server, без перехода в отдельный Flutter-десктоп.

## 1. Запуск и Q2

1. Установить артефакт `QidiAdminStudio_Windows_*_x64` или распаковать
   portable-архив.
2. Открыть мастер добавления принтера и выбрать **Qidi Q2 0.4 nozzle**.
3. Убедиться, что стол имеет размер 270 × 270 мм и переключение в
   «Просмотр» показывает послойный G-code без ошибок.

## 2. Соединение с Raspberry

1. Открыть вкладку `Qidi Admin` (или выбрать `Qidi Admin → Server connection`).
2. Указать HTTPS-адрес Raspberry-сервера и API-ключ; сертификат TLS оставить
   включённым для публичного домена.
3. Нажать `Check server`: должны отобразиться состояние Q2, прогресс и
   температуры.
4. Проверить, что пустой ключ разрешён только для сервера, явно настроенного
   с `ALLOW_ANONYMOUS_LAN=true` в изолированной LAN. Через домен ключ обязателен.

## 3. Камера и команды

1. Дождаться кадров камеры: должны отображаться FPS и фактическое разрешение,
   без растягивания изображения.
2. Ввести безопасную команду, например `SET_PIN PIN=caselight VALUE=1`, и
   сначала нажать `Review G-code`.
3. Поставить команду в очередь, затем проверить её статус, задержку и полный
   ответ Raspberry/Moonraker в журнале.
4. Проверить отмену ожидающей команды и повтор неуспешной команды.

## 4. Отправка печати

1. Нарезать небольшую тестовую модель штатными средствами Orca.
2. В профиле принтера выбрать Print Host **Qidi Admin Server (Raspberry)**.
3. Выполнить отправку: приложение должно загрузить G-code на Raspberry,
   выполнить серверную предпечатную проверку и только затем запустить печать.
4. Убедиться, что статус показывает процент, прошедшее и оставшееся время,
   температуру сопла и стола.

## 5. Безопасность

1. Убедиться, что API-ключ не попадает в 3MF, экспорт пресета или URL.
2. Проверить, что опасная команда блокируется серверной политикой, а `M112`
   требует подтверждения в интерфейсе.
3. Проверить, что роль camera не даёт доступ к паузе, остановке, терминалу и
   запуску макросов.
